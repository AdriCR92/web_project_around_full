# 🌎 Around React

A responsive React application developed as part of the TripleTen Web Development Bootcamp.

This project recreates the original Around The U.S. application using **React**, **TypeScript**, and reusable components while following modern front-end development practices.

## 🚀 Overview

The application allows users to:

- View a gallery of place cards.
- Open image previews in a reusable popup.
- Open popups to edit their profile.
- Update their avatar.
- Add new places.

The current version focuses on migrating the original JavaScript application to a component-based React architecture.
